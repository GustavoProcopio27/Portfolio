## Funcionalidades
- Site bilíngue (Português / Inglês)
- Layout totalmente responsivo
- Navegação por rotas (React Router)
- Interface moderna com Tailwind CSS
- Seção de projetos com destaque visual

## Bibliotecas Utilizadas:
- **i18next** : Utilizada para tradução da página, tornando-a bilíngue.
- **react-icons** : Utilizada para adição de ícones de navegação e de estilização.
- **react-router-dom** : Utilizado para roteamento de páginas
- **react-country-flag** : Para os ícones das bandeiras do Brasil e dos Estados Unidos para o botão de tradução.
- **gh-pages** : Para deploy no Github Pages, em uma url com github.io.








#### Como rodar localmente

```bash
git clone https://github.com/gustavoprocopio27/Portfolio.git
cd Portfolio
npm install
npm run dev
```
